# Vision-Pocket 機能一覧

**対象者**: 10代後半～20代
**デバイス**: スマートフォン主戦場
**フリーミアムモデル**: あり

---

## A. 登録・インポート機能

### A-1. SNS連携登録
- [ ] Instagram連携（シェアシート統合）
  - [ ] 投稿URLの自動キャッチ
  - [ ] OGP画像・説明文の自動取得
  - [ ] 自動ボード分類（オプション）
- [ ] YouTube連携（シェアシート統合）
  - [ ] 動画URLの自動キャッチ
  - [ ] サムネイル・タイトルの自動取得
- [ ] Deep linking対応
  - [ ] SNS内リンク → アプリ起動 → 自動登録フロー

### A-2. 手入力登録
- [ ] URL貼り付け → メタデータ自動取得
  - [ ] OGP画像（なければfavicon）
  - [ ] ページタイトル
  - [ ] 説明文
- [ ] 手動入力（タイトル、画像、説明）
- [ ] 複数URLを一括登録

### A-3. 登録時の詳細設定
- [ ] カテゴリ選択（「行きたい場所」「食べたい物」「買いたい物」など）
- [ ] タグ付け
- [ ] メモ（自由記述）
- [ ] 優先度設定（★★★など）

## F. フリーミアムモデル

### F-1. 無料プラン（Free）
- [ ] 保存アイテム数: 50個まで
- [ ] 公開ボード: 1個まで
- [ ] 共有機能: 基本的な共有リンク生成
- [ ] ボード数: 3個まで
- [ ] ストレージ: 達成写真100MB

### F-2. 有料プラン（Pro）
- [ ] 保存アイテム数: 無制限
- [ ] 公開ボード: 10個まで
- [ ] 非公開ボード: 無制限
- [ ] 共有機能: 全機能
- [ ] ストレージ: 達成写真1GB
- [ ] フィーチャー（トップページ掲載）
- [ ] 広告なし

### F-3. 課金トリガー
- [ ] 50個目のアイテム保存時に「アップグレード提案」
- [ ] 4個目のボード作成時に提案
